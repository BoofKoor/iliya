# وب‌سایت پسته ایلیا — نسخه‌ی نمایشی

نسخه‌ی نمایشی (دمو) وب‌سایت شرکت **پسته ایلیا**؛ یک صفحه‌ی فرود لوکس، فارسی و راست‌به‌چپ با هویت بصری برگرفته از لوگوی شرکت: سبز زمردی تیره، طلایی و کرم.

![پیش‌نمایش](assets/img/og-image.jpg)

## مشاهده‌ی سایت

- **ساده‌ترین روش:** فایل `index.html` را با دوبار کلیک در مرورگر باز کنید.
- **با سرور محلی (پیشنهادی):**

  ```bash
  python3 -m http.server 8000
  ```

  سپس آدرس `http://localhost:8000` را در مرورگر باز کنید.

سایت به هیچ سرویس بیرونی وابسته نیست؛ فونت‌ها، آیکون‌ها و تصاویر همگی داخل پروژه‌اند و بدون اینترنت هم کامل نمایش داده می‌شود. نیازی به نصب یا build هم ندارد.

## انتشار آنلاین با GitHub Pages

1. در مخزن به **Settings ← Pages** بروید.
2. در بخش **Build and deployment** گزینه‌ی **Deploy from a branch** را انتخاب کنید.
3. شاخه‌ی مورد نظر و پوشه‌ی `/ (root)` را انتخاب و ذخیره کنید.

پس از چند دقیقه سایت روی `https://boofkoor.github.io/iliya/` در دسترس خواهد بود.

> برای مخزن خصوصی، GitHub Pages فقط در پلن‌های پولی گیت‌هاب فعال است.

## صفحه‌ها

- **`index.html`** — صفحه‌ی اصلی (معرفی برند، محصولات، صادرات، تماس)
- **`prices.html`** — تابلوی قیمت روز پسته، ویژه‌ی باغداران

## بخش‌های صفحه‌ی اصلی

| بخش | توضیح |
|---|---|
| سربرگ | لوگو، منو (در موبایل منوی تمام‌صفحه) و دکمه‌ی استعلام قیمت |
| معرفی | شعار «طلای سبز ایران، با امضای ایلیا»، نشان چرخان لوگو و لینک قیمت روز |
| نوار قیمت | قیمت لحظه‌ای ارقام به‌شکل تابلوی بورس، با لینک به تابلوی کامل |
| داستان ایلیا | معرفی شرکت، ارزش‌ها و آمار |
| ارقام ممتاز | اکبری، احمدآقایی، کله‌قوچی، فندقی، بادامی و فرآورده‌ها |
| از باغ تا بسته | شش مرحله‌ی فرآوری |
| تعهد ما | ویژگی‌های کنترل کیفیت |
| صادرات | نقشه‌ی مسیرهای صادراتی |
| جعبه‌های هدیه | بسته‌بندی‌های لوکس مناسبتی و سازمانی |
| تماس | اطلاعات تماس و فرم استعلام قیمت |

## تابلوی قیمت روز (`prices.html`)

- خلاصه‌ی بازار: تاریخ و ساعت به‌روزرسانی، شاخص قیمت، بیشترین رشد و افت روز
- نوار متحرک قیمت‌ها و تابلوی کامل با فیلتر رقم، تغییر روزانه و نمودار کوچک روند هفته
- نمودار تعاملی قیمت هر قلم در بازه‌های ۱ هفته تا ۵ ماه (در موبایل به‌صورت پنل کشویی)
- ماشین‌حساب ارزش محصول برای باغدار (با نمایش مبلغ به‌صورت «۲ میلیارد و ۱۵۰ میلیون»)
- ارسال قیمت‌های روز در واتس‌اپ و دعوت به کانال قیمت

### به‌روزرسانی قیمت‌ها

همه‌ی قیمت‌ها از فایل `assets/js/prices-data.js` خوانده می‌شوند. این فایل فعلاً **داده‌ی نمونه** می‌سازد. برای قیمت واقعی، کافی است همین ساختار با داده‌ی واقعی پر شود (دستی، یا بعداً از پنل مدیریت یا API):

```js
window.ILIYA_PRICES = {
  sample: false,                                   // نشان «قیمت‌ها نمونه است» حذف می‌شود
  priceType: 'نرخ خرید پسته‌ی خشک از باغداران',
  updatedAt: '2026-10-13T09:30',                 // ساعت تهران
  items: [
    { id: 'akbari-20-22', group: 'akbari', name: 'اکبری', grade: '۲۰–۲۲',
      history: [{ date: '2026-10-12', price: 2145000 }, { date: '2026-10-13', price: 2150000 }] },
  ],
};
```

`history` از قدیم به جدید است، تاریخ‌ها میلادی (`YYYY-MM-DD`) و قیمت به تومان برای هر کیلوگرم؛ سایت تاریخ‌ها را خودش شمسی نمایش می‌دهد. تغییر روزانه، نمودارها و شاخص به‌طور خودکار از همین داده محاسبه می‌شوند.

## ساختار پروژه

```text
index.html              صفحه‌ی اصلی
prices.html             تابلوی قیمت روز
assets/css/style.css    استایل‌ها (رنگ‌ها و فونت‌ها در ابتدای فایل تعریف شده‌اند)
assets/css/prices.css   استایل تابلوی قیمت
assets/js/main.js       تعامل‌ها: منو، انیمیشن‌ها، شمارنده‌ها، فرم
assets/js/prices.js     تابلوی قیمت: نوار قیمت، جدول، نمودار، ماشین‌حساب
assets/js/prices-data.js  داده‌ی قیمت‌ها (فعلاً نمونه)
assets/fonts/           ایران‌یکان X برای تیترها (تجاری)، وزیرمتن و کورمورانت (مجوز OFL)
assets/img/             لوگو، تصویرسازی‌های پسته، الگوی هندسی و نقشه
assets/img/products/    عکس فرآورده‌ها (فعلاً نمونه)
```

## محتوای نمونه که باید جایگزین شود

این نسخه برای نمایش است و بخشی از اطلاعات فرضی است:

- [ ] **قیمت‌های تابلوی قیمت روز** فعلاً نمونه‌اند و نسبت به تاریخ امروز ساخته می‌شوند
- [ ] **لینک کانال‌های قیمت** (واتس‌اپ و تلگرام) در صفحه‌ی قیمت روز
- [ ] **آمار** بخش «داستان ایلیا» (سال تجربه، تعداد کشورهای مقصد و …)
- [ ] **اطلاعات تماس**: تلفن، واتس‌اپ، ایمیل، نشانی و ساعات کاری
- [ ] **لینک شبکه‌های اجتماعی** در پانویس
- [ ] **مقاصد صادراتی** روی نقشه
- [ ] **سایزها و توضیحات ارقام** پسته
- [ ] **عکس فرآورده‌ها** (`assets/img/products/`): عکس‌های فعلی نمونه و از منابع اینترنتی‌اند و پیش از انتشار رسمی باید با عکاسی خود ایلیا جایگزین شوند
- [ ] **تصویر ارقام پسته** فعلاً تصویرسازی برداری است و می‌تواند با عکس واقعی جایگزین شود
- [ ] **فرم استعلام قیمت** فعلاً به سرور وصل نیست و فقط پیام موفقیت نشان می‌دهد
- [ ] تگ `noindex` در `index.html` هنگام انتشار رسمی حذف شود
- [ ] **لایسنس فونت ایران‌یکان X**: ثبت لایسنس وب در fontiran.com و درج کد ۶ رقمی آن در `assets/fonts/IRANYekanX-FontLicense.txt`

## مراحل بعدی پیشنهادی

1. گرفتن بازخورد مدیریت روی طراحی
2. جایگزینی محتوای واقعی و عکاسی حرفه‌ای از محصولات
3. نسخه‌ی انگلیسی برای مشتریان خارجی
4. اتصال فرم به ایمیل، پیامک یا پنل مدیریت
5. خرید دامنه و هاست و انتشار رسمی
